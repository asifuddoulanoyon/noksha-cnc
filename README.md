# নকশা CNC

ফার্নিচারের (আলমারি, খাট, ড্রেসিং, শোকেস, দরজা, জালি) নকশা ডিজাইন করে সরাসরি CNC রাউটারের G-code ফাইল (.nc / .tap) তৈরির মোবাইল অ্যাপ।

- রেডি নকশা: স্যাম্পল বাছুন → নিজের মাপ দিন → ফাইল নিন
- নিজে ডিজাইন: আকৃতি, বর্ডার, নকশা, কোণা, জালি — ধাপে ধাপে
- ছবি থেকে: নাম/লোগো/নকশার ছবি থেকে G-code
- মাপ হিসাব: আলমারি ও খাটের কাটিং লিস্ট

অ্যাপ: https://asifuddoulanoyon.github.io/noksha-cnc/

APK: এই লিংক pwabuilder.com-এ দিয়ে Android প্যাকেজ নামান।
